Features

Six trace surfaces. One clean sweep.

Every artifact Windows keeps about your activity is targeted by a dedicated module — no leftovers, no manual hunting through system folders.

📓

USN Journal Wipe

Deletes and re-creates the NTFS change journal so executed file paths, renames and deletions stop being recoverable.

🪵

Event Log Purge

Clears Security, System, Application and PowerShell operational logs — including 4688 process-creation entries.

⚡

Prefetch Cleanup

Removes .pf files and the ReadyBoot trace history that reveals which executables were launched and how often.

🧬

Registry Trace Scrub

Wipes UserAssist, MUICache, Amcache, RecentDocs, RunMRU and BAM/DAM keys tied to executor and spoofer activity.

🛡️

Post-Injection Mode

A one-click profile built for after cheat injection or spoofer use — it targets exactly the artifacts those tools leave.

♻️

Restore Point Aware

Optionally removes stale shadow copies and Volume Snapshots that could hold pre-clean versions of the same traces.

How it works

Three steps from traced to clean.

No configuration files, no command-line flags to memorize. Trace Cleaner runs as a single portable executable.

1

Launch as Administrator

Run the portable Trace Cleaner executable with elevated rights. It performs a read-only scan first and lists every trace surface it can reach on your build of Windows 10 or 11.

2

Pick your clean profile

Choose Post-Injection, Spoofer or Executor — each profile selects a tuned set of USN journal, event log, prefetch and registry targets instead of nuking everything blindly.

3

Sweep and verify

Trace Cleaner wipes the selected traces, re-initializes the USN journal and produces a verification report confirming that the targeted artifacts no longer exist.
